# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto se adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [Unreleased]

### Añadido
- Sistema de instalación automatizada (install.sh para Linux/macOS, install.bat para Windows)
- Archivo requirements.txt con dependencias del proyecto
- Archivo requirements-dev.txt con herramientas de desarrollo
- Documentación completa de instalación en README.md
- Guía de setup en SETUP.md
- Archivo .gitignore para control de versiones
- Script compile_ui.sh para compilación automática de interfaces
- Soporte para múltiples bases de datos (SQLite, MariaDB, PostgreSQL)

### Características
- Sistema de autenticación con bcrypt
- Interfaz gráfica con PySide6
- Arquitectura MVC modular
- Gestión de empresas
- Sistema de módulos extensible
- Modo de rescate para administración
- Estilos personalizados QSS
- Compilación automática de archivos .ui

## [0.1.0] - 2026-01-11

### Añadido
- Versión inicial del proyecto
- Sistema de login
- Módulo de empresas
- Módulos de ventas, almacén, configuración
- Base de datos SQLite por defecto
- Interfaz oscura profesional

- `Añadido` para funcionalidades nuevas
- `Cambiado` para cambios en funcionalidades existentes

- `Eliminado` para funcionalidades eliminadas
